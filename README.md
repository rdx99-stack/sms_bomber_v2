# 🚀 Worm SMS Bomber V2 (Advanced)

A high-performance, multi-threaded SMS bombing tool designed for penetration testing and stress testing. Features IP rotation, random delays to avoid bans, and a clean UI.

## ✨ Features
- **Multi-Threading:** Send requests simultaneously using multiple threads.
- **Anti-Ban System:** Random `User-Agent` and `X-Forwarded-For` headers to bypass IP blocking.
- **Smart Delay:** Random sleep intervals to prevent Rate Limiting.
- **Cross-Platform:** Works on Windows, Linux, and macOS.
- **Real-time Status:** Live success/failure logging with color codes.
